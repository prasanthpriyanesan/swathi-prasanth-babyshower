# 🚀 Deployment Guide: Hosting Your Baby Shower Website Live

Follow this simple guide to deploy your website online for free and start collecting real RSVPs from guests on their mobile phones and computers!

---

## ⚡ Option 1: 1-Click Hosting on Vercel (Recommended - Takes 2 Mins)

1. **Upload / Push your code to GitHub**:
   - Go to [github.com/new](https://github.com/new) and create a private or public repository (e.g. `baby-shower-website`).
   - Run these commands in your project terminal:
     ```bash
     git init
     git add .
     git commit -m "Initial commit of Indian Traditional Baby Shower Website"
     git branch -M main
     git remote add origin https://github.com/YOUR_USERNAME/baby-shower-website.git
     git push -u origin main
     ```

2. **Deploy on Vercel**:
   - Go to [Vercel.com](https://vercel.com) and sign up for free with GitHub.
   - Click **"Add New"** ➔ **"Project"** ➔ Select your `baby-shower-website` repository.
   - Click **"Deploy"**!
   - Vercel will give you a live URL in seconds (e.g. `https://ananya-vikram-babyshower.vercel.app`).

---

## 🗄️ Option 2: Connecting a Free Supabase Cloud Database (For Live RSVPs Across All Guests)

Currently, the app stores RSVPs in a smart local state so you can test it immediately. To sync RSVPs across all guest devices live into a central cloud database:

1. Create a free account at [Supabase.com](https://supabase.com).
2. Click **"New Project"** and create a project.
3. In your Supabase SQL Editor, run this quick setup script to create your 3 tables:

```sql
-- 1. RSVPs Table
create table rsvps (
  id bigint generated by default as identity primary key,
  name text not null,
  phone text not null,
  count text not null,
  diet text not null,
  song text,
  created_at timestamp with time zone default timezone('utc'::text, now()) not null
);

-- 2. Blessings Table
create table blessings (
  id bigint generated by default as identity primary key,
  author text not null,
  relation text,
  text text not null,
  created_at timestamp with time zone default timezone('utc'::text, now()) not null
);

-- 3. Votes Table
create table votes (
  id bigint generated by default as identity primary key,
  choice text not null,
  created_at timestamp with time zone default timezone('utc'::text, now()) not null
);

-- Enable public read/write access for guests
alter table rsvps enable row level security;
alter table blessings enable row level security;
alter table votes enable row level security;

create policy "Public insert rsvps" on rsvps for insert with check (true);
create policy "Public select rsvps" on rsvps for select using (true);

create policy "Public insert blessings" on blessings for insert with check (true);
create policy "Public select blessings" on blessings for select using (true);

create policy "Public insert votes" on votes for insert with check (true);
create policy "Public select votes" on votes for select using (true);
```

4. In your **Vercel Project Settings ➔ Environment Variables**, add:
   - `VITE_SUPABASE_URL` = (Your Supabase Project URL)
   - `VITE_SUPABASE_ANON_KEY` = (Your Supabase Anon Public Key)

And you're done! All RSVPs from guests anywhere in the world will save live into your Supabase database and appear in your Host Admin Dashboard & CSV downloads!
